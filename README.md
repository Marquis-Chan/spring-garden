# 春日小花园 · 林间探索版

直接打开 **春日小花园.html**。单文件约 2.6 MiB，插画、代码和十五项真实录音全部内嵌，可离线玩。孩子的画面没有文字、分数或任务。

右侧的叶拱门进入亚洲树林，树林右侧的藤门通向美洲树冠；反向入口可以回来。经过入口只预览，点击才切换，按住拖动云朵跨过门不会换页。左上角的花草／树冠图案是第二入口。每页保留自己的花、动物和物品状态，昼夜在三页之间共享。

平原保留小鸟、三只蝴蝶、鱼儿和动物来访；长颈鹿、斑马、河马、乌龟、企鹅轮流出现，猫狗可从图案邀请，之后会离开。亚洲树林有东方角鸮、蜜蜂、松鼠、啄木鸟，亚洲象、老虎、亚洲黑熊、印度孔雀、印度犀牛轮流做客。美洲树冠有二趾树懒和吼猴。平原是开放绘本场景，企鹅属于来访者；不宣称这些动物属于同一个真实生态群落。

可重复探索：摘苹果时树上少一颗、篮子里多一颗；点篮子倒出，再点地上的苹果逐颗拾回，或点篮子一起收回。小狗追逐并衔回同一颗球。大象先把鼻子伸到溪水里、抬鼻喷水、浇到右侧可达的花，白天有光时出现彩虹。点蜂巢可看蜜蜂接触花心、后足带花粉、返回树洞。点击枝头的果子，果子落到地面，熊才会闻果和取食；三颗果子不凭空补充。长颈鹿、吼猴、树懒通过实际嘴／手与物品接触完成取食。

角鸮白天被点击也保持睡眠；夜幕完成后睁眼，点击拍翅飞到另一根支撑枝，落枝后才鸣叫。树懒夜间有更多缓慢取叶，始终保留其他肢体的枝条支撑。夜晚蜜蜂不外出采集，半途入夜先返巢。孔雀会收屏、拍翅上枝休息，白天再回地面；松鼠能从实际近枝取坚果送到嘴边，啄木鸟的短敲击有接触点的碎屑。宽叶可被压动、抖下露珠，月光下拨开叶片会发现原来藏着的小萤火虫。落叶来自有限的枝头叶片，可以翻面；点树旁倒木能看蜗牛慢慢探出。

点太阳／月亮切换昼夜，月牙和满月交替，五角星各自闪烁。按住云朵可拖动，松手后停住；点云朵会移到日月前遮光，再点已停住的云恢复漂移。天空在树林中保留开口。雨天、海底、四季保留独立扩展配置，本版仍是春季晴天。

首次点击允许声音。右上角为声音和全屏图案。**Ctrl + Shift + P** 打开家长设置并暂停，音量上限 60%，默认 46%；时长为不限时、5、10、15 分钟。家长设置可在浏览器允许时保存。切换窗口会暂停动作、声音与游戏时钟，回来不补播。右键不会弹出游戏内菜单。

十五项录音含原有十二项、东方角鸮叫声、大斑啄木鸟敲木声、蜜蜂振翅环境声。后两项不称作动物叫声。熊、树懒、松鼠未找到物种与许可都可靠的录音，保持安静；鱼、乌龟、蝴蝶也没有替代音。前景叫声按有效信号电平匹配，蜜蜂环境声低约 10 dB。老虎的威胁性咆哮不作为每次触碰的愉快反馈；长颈鹿研究录音仅在夜间语境使用。

[叫声核对.html](./叫声核对.html) 是独立家长试听页，含处理片段、原始片段、作者与许可证。原素材在 `assets`，新增来源与加工记录见 `docs/forest-audio-notes.md`、`assets/forest-credits.json`。文字与来源不进入儿童画面。

开发：`node tools/build.mjs` 构建游戏，`node tools/build-audio-review.mjs` 构建家长试听页。新场景／行为实现位于 `src/world.js`、`src/scenery.js`、`src/forest-art.js`、`src/garden-engine.js`；旧 `src/game.js` 保留为原版参考，不再进入本版构建。

验证：`node --test tests/logic.test.cjs tests/motion.test.cjs tests/nature.test.cjs tests/world.test.cjs tests/engine.test.cjs`；`node tests/release-audit.cjs` 检查内嵌声音、脚本语法与离线依赖。`engine-harness.cjs` 是不渲染的 SVG 状态模拟，不是浏览器。已有使用 Playwright 的旧测试面向旧引擎，不作为此次验收依据。

本轮完成了状态集成测试和静态插画检查。当前浏览器策略阻止自动访问本地文件，未绕过限制，尚未完成 Chrome／Edge 真机动画、触摸及孩子试玩验收；静态检查不能替代 CSS 动画观感与实际听感。
