# 河岸、桉树和雨林里的新伙伴

三个地方各有一个宝宝能亲手发现的小故事。点小鳄鱼看它从岸上滑进水里，点一片桉叶看考拉拉到嘴边，点金刚鹦鹉听另一只鸟回答。鼠标和手指都能玩，动物、树叶和树枝沿用游戏里的轮廓提示。

## 淡水河岸 · 小尼罗鳄

河马池右手边留一段向水里倾斜的沙岸。小鳄鱼平时伏在这里，偶尔抬抬鼻尖。点它，它会张嘴发声，合嘴后沿弧线爬下沙坡，尾巴顺着身体刚走过的路弯过去。鳄鱼入水处泛起波纹，附近有小鱼浮头。

等鳄鱼浮稳再点河马。蓝色水波从河马身边一圈圈推开，碰到鳄鱼时，它才抬起鼻尖。此时再点鳄鱼，它会转身爬回沙岸。河岸上原来的小鸭、乌龟和给河马刷牙的地方仍可单独点到。

## 桉树林 · 考拉和银眼鸟

沿大地图从亚洲树林往美洲雨林拖，中间是一小片桉树林。地图路牌与底部的考拉头像都能进近景。一根低横枝承住考拉，另一棵树给银眼鸟留了两个歇脚点。

- 点考拉，它会抬头，发出成年雄考拉低沉的吼声。
- 点嘴边那簇嫩叶，它伸手握住叶柄，拉弯细枝，送叶尖入口。旁边的鸟感到枝条晃动，会展开翅膀换个位置。
- 点承重横枝，考拉随树枝轻摆。点银眼鸟，它会先唱再飞，醒着的考拉侧耳听。夜里银眼鸟收翅睡觉，考拉仍可以吃叶。白天考拉偶尔也会打个盹，点熟睡的小动物会飘出 Zzz。

## 美洲雨林 · 绯红金刚鹦鹉

雨林右前方的低枝方便孩子第一次找到鹦鹉，第二根枝条在巨嘴鸟左上方。依次点鹦鹉，它会展翅鸣叫、振翅换枝、用浅色钩喙梳理红肩下的金黄覆羽。巨嘴鸟会转头听，等鹦鹉的一组叫声结束再答一声。

点树猴旁那根能掉的香蕉，小猴在地上捡，鹦鹉在低枝上探头看。它若停在高处，会先飞回低枝。晚上的鹦鹉在枝上睡觉。

## 试玩后做的调整

第一轮在桌面画面里看出鹦鹉飞过时遮住了巨嘴鸟的脸。第二轮将航线移到巨嘴鸟左侧，调整转弯的朝向，并让它梳理靠镜头的一侧翅膀。河岸也调整了鳄鱼转弯时的尾迹，使后半身随肩背走过弯道。

桉树林抬高了宽屏取景，让树冠和太阳之间露出天空。竖屏又将镜头拉近，放大抓叶的手、叶尖和银眼鸟。在 390×844 触屏上复点了两处鸟枝、横枝和嫩叶，又走了一次白天、夜里喂食、回到白天的完整过程。

离线 Chrome 在桌面、手机竖屏和手机横屏都实际启动了四段录音。逐个比较浏览器播放的声音采样与内嵌音轨，四段均吻合。测试也确认两只睡鸟都能点出 Zzz。
