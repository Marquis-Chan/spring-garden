# 牧场的五种动物声音

奶牛拖长的哞声和小羊较轻的咩声分别来自牛舍和羊圈。鸡舍里有三种可辨认的声音：母鸡低低地咯咯叫，公鸡把一次打鸣分成几拍，鸡仔发出短而高的啾声。
