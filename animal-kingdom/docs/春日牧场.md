# 春日牧场

红谷仓是牧场在大地图和场景栏里的同一个标志。宝宝一进来就能看见全部十二只动物。两头花奶牛的斑纹不同，两只羊羔一深一浅，前面留给一家七口的鸡群，柯基沿最外侧的小径往返。游戏画面沿用无文字的探索方式。

| 点哪里 | 孩子会看到什么 |
| --- | --- |
| 干草或一头奶牛 | 点干草，两头奶牛轮流来吃。点牛头或身子，可以选这头牛。它走到草边才低头，嘴碰到干草后草堆逐渐变小。 |
| 任意一只羊羔 | 被点的羊先蓄力起跳，另一只稍后跟跳。两只羊各有落脚的位置。 |
| 公鸡 | 公鸡伸颈打鸣，母鸡招呼五只鸡仔，它们一只接一只走向谷粒。 |
| 谷袋或母鸡 | 谷粒从袋口撒开，母鸡和五只小鸡各到一处啄食。孩子能看见谷粒随鸟喙落下而减少。 |
| 一只小鸡 | 它自己啾叫、张开小翅膀，旁边一只小鸡随后也扑一扑翅。 |
| 柯基 | 白天它汪一声，停下来侧头看人，又继续沿围栏巡视。夜里也能点它，它会安静回应。 |

太阳落下时，正在跳的羊先落地，牛羊回到草地上伏下，鸡群收翅闭眼。点哪只，哪只头边就浮起小小的 Zzz。夜里只有小狗巡逻，谷袋和干草不会把动物叫醒。天亮后，睁眼前点下的动作会在醒来后回应一次。
