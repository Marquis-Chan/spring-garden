# 鸭妈妈、北极熊、绯红金刚鹦鹉与刺猬的录音

四段声音均取自录音者采集的实录。剪辑保留原始音高、速度和每声之间的停顿，削弱了底噪，调整了播放响度，并在切口加了短淡入淡出。离线资源格式为单声道、22,050 Hz、16 位 PCM WAV。
