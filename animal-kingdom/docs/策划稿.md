# 雨后小池塘｜动物王国的第一块

两岁孩子无需读说明，就能从眼前发生的动作发现下一处可以玩的地方。Steam 儿童游戏头部作品的体验是长期参照。下列评议借鉴了所列设计师与作品公开分享的设计方法，由项目团队完成。

| 讨论 | 不同意见 | 决定 |
| --- | --- | --- |
| 一、框架 | 宫本茂与《马里奥》重视初见就能上手。低龄视角关注寻找目标的负担。《塞尔达》的地标能帮助玩家记住已经发现的位置。 | 固定镜头、一处浅水、两位主角、两个明确落点。打开即可动手。 |
| 二、交互 | 儿童触屏应一步就看到响应。《马里奥》强调输入位置会改变结果。陈星汉的设计强调让玩家自己建立联系。 | 蛙、石、叶、水、鱼都可点。点水引鱼，拖水能改道。蛙跳时记住最后一个落点，两种操作顺序都能让鱼在蛙身边探头。 |
| 三、细节 | 孩子容易连续点按。动作的重量来自蓄势、腾空和接触。声音、静音和连续输入要独立处理。 | 指针一落下就给反馈。趾盘贴稳才溅水，鱼能改向和躲石头。联动后可以引鱼离开再重玩，叫声保持清楚。 |
| 四、视觉 | 视觉评审关注材质一致。《马里奥》的动作重视轮廓和幅度。《塞尔达》视角让石和叶承担地标作用。陈星汉的氛围视角让昼夜与水面串起这些行为。 | 固定俯视的原创软陶风水景。暖黄岸线、青绿水面、金色鱼与太平洋树蛙共用 3D 光线和水层，灯光要保住轮廓。 |

开场就能看见石上的蛙、带花的大荷叶和缓游的鱼。以半分钟内第一次触发、一次主动换目标和一次联动作为可观察的设计目标。游戏画面只显示玩点和声音、天气图标。

1. 先点空叶，蛙会蹲下、起跳、落稳。点叶边的水把鱼引过来，鱼探头，蛙转过来鼓喉。
2. 也可以先点水引鱼，再点同侧空石或叶。联动后换一个位置继续玩，池塘会回应新的选择。
3. 点日月切换昼夜，星星会亮起，月相随夜晚轮换。拖云遮住日月，遮得越多越暗，松手后云停在原地。

工程把角色建模、动物行为、水与光、输入分开实现，再编成可双击打开的单文件。视觉、玩法和项目经理分别复核真实画面、输入和验收证据。第二块计划是林缘，让兔子、鸟与草丛建立新的因果关系，通过验收后逐块纳入原有阵容。

## 第二块设想 · 草丛里有谁

**第一眼**能看到一对露在宽草丛外的兔耳，和右上低枝上转头的小鸟。镜头略俯看一块明亮空地。窄屏让兔子和鸟上下错开，宽屏向两边展开林缘，草后的出口、兔子的落地和鸟的栖枝都放在共同可见的范围。另一处草丛瘦高、有两根浅色草穗，孩子能记住两个位置。

- **先碰草丛。** 指尖附近几根草先弯，兔子探鼻、压低身体，再蹬出一两步。它从低枝下面经过时，小鸟才侧头、拍翅换枝。孩子再碰停稳的兔子，它会跳向另一处草丛，换一个地方探出来。
- **先碰小鸟。** 小鸟从枝头飞下，在兔耳附近啄一根带籽的草穗。草穗碰到鸟嘴才弯下去，兔耳随即转向同一处，露出一点脸。孩子可以继续碰草丛，或再碰鸟让它回枝。两条路在第一触就有回应，可以边看边选下一步。
- **动作、声音和提示。** 兔子用后腿蹬，前爪先接地。鸟先离枝，双翼展开，落枝前展尾减速。鸟声用与角色相符的实录，草叶和脚步用轻的实地录音。鼠标移近时用草尖轻弯和简明光标提示去哪里碰。触屏从开场的兔耳动静发现草丛。
- **试玩判据。** 点草立即看得到局部反应。兔子走远处的路线时，小鸟应留在枝上。碰草、碰兔、碰鸟分别要有能辨认的结果。用宽屏和窄屏各试玩两轮，留意第一次能否自行找到玩点、跟上两只动物的先后，以及有没有主动换一个地方再玩。

## 同一张地图的两种距离

开场从全景看池塘和林缘，小路把石台、荷叶与低枝串在一张图上。全景可以直接碰动物。小路的荷叶、树图标让镜头沿地面走近对应区域，左下的全景图标带回原构图。白昼、月相、云的停靠、静音和动物各自的状态接续。窄屏把池塘排在林缘下方，尽量让四个动物在进画面时都能看见。

地图、两块地面和全部动物共用一个 3D 场景。拖水引鱼、拖云遮光继续用各自的动作。第一张地图先由蛙、鱼、兔和鸟测试从一处走到另一处，再按实际画面的大小和可读性增加阵容。

## 果园 · 树下的四位邻居

池塘、林缘已签收浏览器试玩。果园的玩法、视觉和项目经理完成开工前评议，选择把苹果树放在地图前方的三角路口。近景一眼能看到果梗、滚果的短坡、地上的柯基和果篮。在一侧留出猫和蝴蝶的花丛，另一侧是蜂巢和蜂花。猫和柯基的身体保持完整轮廓，蝴蝶与蜜蜂借翅形、色彩和各自的落点来分辨。

1. 点红苹果，果梗立刻动，同一颗果离枝、落地、弹一下、滚进篮子。柯基在果实落地后才追，果停了再低头嗅。几颗同时摘也各自计算。
2. 点猫会伸懒腰。蝴蝶换花时，猫只跟近处的蝴蝶。点蜂巢，两只蜂从巢口出来，各自飞往另一片花。点飞虫和点花都有直接反馈。
3. 入夜猫狗睡觉，小蜂回巢，蝴蝶停在花叶间。点睡兽可看到 Zzz，夜里仍能摘苹果。天亮后可以从这些位置接着玩。
4. 两轮桌面、竖屏实机验收逐次记录动物占位、起落接触、快速点按、果子守恒、日夜、关卡返回和无网播放。下一场景在本场景复测和独立签收之后开始。

## 第四块 · 草原的水和树叶

果园签收后，玩法、视觉和项目经理评审了草原。浅水、两朵花、两丛低叶和晒石组成四个能记住的位置。大象、长颈鹿、斑马和公狮共处一景。长颈鹿用高度腾出前排的空间，公狮留在晒石，斑马只在眼前空地往返。

1. 点花会先晃一晃以示选中。点大象，象鼻触水时出现涟漪，鼻尖抬起送出一弧水。等水花抵达，当下选中的花才打开。白天能在落水边看见小彩虹，夜里和浓云遮光时只看见水珠。
2. 点鹿或点不同的枝，鹿伸长脖子，嘴碰嫩叶才咬下。叶子摇落到斑马附近时，斑马才转耳找它。让斑马跑到另一处，再点同一枝，可以看到落叶依旧会落下，斑马留在原地。吃过的叶簇会再长回来。
3. 点斑马，引它沿看得完的小路来回小跑，脚踩过才出现蹄印。入夜斑马站着打盹，点它会出现 Zzz。点狮子看抬头张口和听吼声，点晒石看它伸前爪。吼声和动作一起开始，爪子保持接触石面。
4. 全景的伞形树标记通到草原。镜头走近时动物在原位，返回后浇过的花继续保留湿度。云的位置及昼夜也跟着带过去。宽屏和竖屏都应看得出四只动物的轮廓，下一块在两轮试玩和签收之后启动。

## 第五块 · 河岸的水波

草原签收之后，玩法、视觉和项目经理共同批准河岸。河湾按浅石、深水、干岸安排乌龟、河马、白犀牛。两条已有鱼顺各自的泳道活动。全景的小水湾图标和草原边缘的小路都可抵达河岸，两边能相互走近。返回保留动物位置和天气。

1. **看一道波走过去。** 点河马就抬头张嘴和发声。胸前落回水面时，才有水花和向外扩的波。水波经过，近浮叶先晃，远叶随后晃。乌龟在波路旁且没缩头时才转头。依次把龟带到近石、远石，可以观察同一动作的两个结果。
2. **从石头到水里。** 点龟壳，可以看它沿壳口收回头，再原处探出来。点空踏石才换位置，途中从划水过渡到用爪攀浅石，远岸停下晒背。夜里，在途的龟到站才休息，点睡龟出 Zzz。河马仍可回应。
3. **让犀牛找草。** 点它会呼气、沿岸小跑几步。点另一丛草会先看到草尖弯下，犀牛到对岸上那丛草才低头探鼻。两只陆地动物的路留开，也给犀牛侧面的眼、角和脚留出镜头空间。
4. **小手可以随意选择。** 水面一点出现水纹，点到任一鱼会短暂潜游，随后在自己的活动区里游出。近岸石、草、龟壳、鱼身和进出场景的路牌在竖屏要各自留出位置。

## 回到林缘 · 五种动物同屏

河岸签收后才评审林缘扩展。新角色选松鼠、赤狐与大斑啄木鸟。树根、枯木和枯叶在旧草窝旁形成三个新玩点，在地面和树上为五种动物分别留出空间。原有兔子受草动而跳、小鸟因兔经过而换枝、鸟嘴啄草穗带动兔耳等行为继续复验。

1. 松鼠抱着同一枚松果在两个树根间换位置，点低枝还可以沿矮树干攀上去。爪抓住、身子再上移，松果跟着双爪一起动。啄木鸟敲到枯木，近处的松鼠才会抬耳找声源，远处可以继续抱果。
2. 啄木鸟的双脚和尾尖支在枯木上，头后收再把喙伸到木面。点枯木另一处，鸟先短移、抓稳，然后再敲。录音在碰木时启动，并用少量碎屑让静音时也能看懂。
3. 点枯叶，叶堆先轻动。狐狸侧耳、转脸、凑近探鼻，等前爪碰到叶堆才拨开。点狐狸换另一处灌丛，路线不穿兔子的草窝。入夜狐狸仍可动，松鼠和啄木鸟休息、点它们出现 Zzz。

## 亚洲树林 · 地面、低枝和高枝

林缘扩展签收后，玩法、视觉和项目经理批准四只动物同屏。左侧月牙熊在果枝下，中央老虎在软土一侧伸展，右侧孔雀开屏时留出完整扇面。角鸮两处停位在后方高枝，低枝留给孔雀。

1. **熊摘叶和捡果。** 点熊或嫩叶，熊先起身，前掌碰到低枝才把那片叶带到嘴边。点橙色果子，果子离梗后落地。近果会引它走过去捡起，远果落在原地。吃完后长一颗新果，可以重玩。
2. **虎伸爪和闻草。** 点老虎会伸前爪并回应一段实录。点旁侧草，草尖先动，虎再沿开阔地走过去，站稳才探鼻。脚掌离地和落地按地形接续，条纹随关节动。
3. **孔雀开屏和上枝。** 白天点孔雀开屏，再点可收，连点沿当前开度反转。羽眼斑跟每片羽毛一起展开。入夜收好屏才蹬地拍翅，到低枝抓稳后睡觉。白天遮太阳只是暗一些，孔雀仍能开屏。
4. **角鸮昼眠夜飞。** 白天点合眼的角鸮只出 Zzz。夜里点醒着的角鸮，它先转头开喙，保留一整组实录，再拍翅到另一根高枝。再亮前未起飞时取消换枝，已经飞起时先落稳。

## 雨林 · 沿枝够果

亚洲树林签收后，雨林评审通过。左边卷尾猴和双香蕉，中间倒挂的树懒，右上保留两段巨嘴鸟栖枝。厚叶和藤放在动物的动作后侧，香蕉、食叶和红果在亮处露出来。

1. **卷尾猴吃香蕉。** 点猴或一根香蕉，它伸手到果梗，香蕉离开枝头后跟手进嘴，吃完在原位长回来。另一根够不到的香蕉先引猴短跳换枝，爪抓稳再伸手。连点一根香蕉也只摘一次。夜间先到安全的枝，再合眼休息。
2. **树懒吃叶和小憩。** 开场清醒。叶子先晃，空出的前爪沿脸侧绕到眼睛下方送叶，另一只前爪和两只后爪持续扣枝。白天闲置一段时间后偶尔小憩，点睡姿有 Zzz，醒后可再吃。
3. **巨嘴鸟叼果和换枝。** 点近处红果，喙碰到后叼取同一颗果，在喙上方短抛再接。点鸟拍翼换一根枝，到远处再点同一颗果只会转头，果留在枝上。鸟可从两根枝之间往返。

## 海岸 · 两只企鹅的下水路线

雨林签收后，玩法、视觉和项目经理确认最后一站。温带礁石围出浅湾，两只非洲企鹅一前一后，各有一条湿岩缓坡和一块圆岸石。两条鱼游在浅、深水区，孩子可以在全景点浪花图案进入，也可以沿河岸边的路标走过去。

1. **点身体看摇步或展鳍。** 陆地上每只企鹅都能轻摇着走几步、举起鳍，带一组真实的联络叫声。黑背白腹、脸侧细斑和蹼脚保持连贯。
2. **点缓坡看滑水。** 企鹅先在坡顶屈腿伏低，等胸腹贴到坡面才滑下。胸腹越过水线时，水花和涟漪从接触处出来，波及的一条鱼游开。点水可单独起涟漪，点任一条鱼可让它游开。
3. **回岸与夜眠。** 点自己的圆岸石，水里的企鹅转回来，沿自己下水的坡贴地上岸，脚蹼踩稳再抬胸。连点同一坡不重复进水，滑途中点岸石可记一次回岸。夜里先完成当前动作，再上岸闭眼。点睡姿有 Zzz，天亮后接着玩。

## 近景视角与动物邻居

在雨林和亚洲树林把视线降到从动物身前看的高度，八个近景分别取景。林缘、果园、草原也降低俯角。池塘、河岸和海岸保留看清水波、鱼和落脚处需要的俯角。竖屏要看得见三处活动入口，远近枝位和路线图标继续分开。

- **亚洲树林。** 点孔雀蓝色身体开收屏，开屏后点羽眼会抖动羽轴和轻转扇面。点浅石种子，收好羽屏后走过去，一粒一粒碰喙才啄掉。抖屏会让近处老虎抬眼动耳，虎探动附近草簇时孔雀也会侧头。白天角鸮仍在高处休息。
- **雨林。** 点树懒身体，它从脸侧伸出空爪；点嫩叶摘食；点露出来的短枝，叶先动、树懒再抱枝轻摆。三只承重爪贴着原来的枝。猴子踩稳邻枝时，清醒的树懒才转脸看。树懒摆到最大幅度时，近枝的巨嘴鸟会转头，远枝照旧。
- **同场回应。** 利用距离、真实接触和清醒状态控制响应。相邻动物接一个看得懂的动作，正在取食、飞行或休息的角色保留自己的动作。

## 九个场景的邻居和发现入口

在全景或近景按住拖动，短点仍触发对应的动物或东西。移动过拖动门槛便结束这次点按，松手也不会补播动作。池塘近景的水依然能直接拖来引鱼。光晕随物件和镜头移动，动物停在原处呼吸、摆尾、转头或小幅划鳍时，淡色弧也能帮孩子认出可点的位置。

| 场景 | 开场安排 | 同场可发现的因果 |
| --- | --- | --- |
| 池塘 | 青蛙和三条鱼分泳道 | 主蛙和主鱼在荷叶边相遇；近水纹让支流游过的小鱼甩尾 |
| 林缘 | 兔、鸟、狐、松鼠、啄木鸟 | 兔从低枝下面过去，小鸟换枝；啄击听得见的近松鼠转耳 |
| 果园 | 柯基、猫、蝴蝶、巢口悬停蜂，点巢后有两只蜂 | 落果让柯基去嗅；蝶飞到近处时猫才转脸 |
| 草原 | 象、鹿、斑马、狮 | 长颈鹿吃叶，叶落近处斑马才动耳；象水到指定花丛才开花 |
| 河岸 | 河马、犀牛、乌龟和两条鱼 | 河马沉入水面推动水波，近处龟和鱼收到不同反应 |
| 亚洲树林 | 熊、虎、孔雀、角鸮 | 中间果先着地，虎从右边到场伸爪探果，熊从左边来捡吃；孔雀抖扇让虎抬头 |
| 雨林 | 树猴、地猴、树懒、巨嘴鸟 | 树上猴拨落新香蕉，地猴走过去捡同一根。树懒抱枝摆大一些，只让近枝巨嘴鸟看过来 |
| 海岸 | 两只企鹅和两条鱼 | 企鹅从自己的坡滑入水，波到近鱼才让它游开。两只企鹅仍沿各自坡回岸 |
| 海底 | 座头鲸、宽吻海豚、鲨鱼、小丑鱼、海马、海星 | 点鲸带出水流，海豚转身回应。鲨经过时小丑鱼躲进海葵，小丑鱼从海马附近游过时海马探身。海星碰贝壳后气泡上浮，小丑鱼转头 |

亚洲树林镜头在原角度上增加 10°，保留看到完整扇面，同时露出种子盘和动物脚下。海底以岸边的鲸尾路标进入，也可以从全景潜入。鲸、海豚采用 NOAA 实录，动作连锁只带视觉反馈，孩子可以边看边试。[海洋动物录音](https://www.fisheries.noaa.gov/national/science-data/sounds-ocean-mammals)

同种动物可有常驻和短访两种出现方式。池塘的三条鱼和雨林的两只猴各有自己的活动区域。果园第二只蜂从巢里飞出来，玩完会归巢。点海葵时，第二条小丑鱼从礁石边游出来，可单独点它去摆尾，几秒后它会钻回去；再点海葵又能叫它出来。
