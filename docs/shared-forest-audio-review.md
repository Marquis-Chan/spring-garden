# 单树林与叫声整体审查 · 2026-10-19

已将场景收为平原和一片树林，保留 23 类动物形象、昼夜及既有摘果／取食／喷水玩法；本地离线 HTML 已重新构建。合并树林是儿童绘本乐园，不作为真实自然共栖群落的说明。

## 声音根因与处理

老虎没有声音的直接原因是 `voice()` 明确排除了 tiger，而拨叶分支也没有调用声音；现在恢复真实原录音绑定，每次完整动作只发声一次。该素材来源语境仍是圈养老虎低吼，不将其标作快乐叫声。

狗原活动段约 −18.24dBFS，本轮增加约 3dB 至 −15.24dBFS，峰值约 −2.55dBFS；音量设置和静音行为保留。猫、孔雀参考音色没有改动，猫和河马的片段不作重复处理。

所有 17 项已有录音的完整反馈长度至少达到猫叫 1.96 秒。短素材保留完整原速短叫，用 0.18 秒间隔分次重复；啄木鸟用 0.25 秒间隔。不是放慢、变调，也不是补一段无声凑长度；未新增假叫声或替换物种。原始素材、作者、许可证、原截取位置保持可追溯。

另外两项容易造成“点了没声音”的问题已修复：

- 猫和孔雀不再在悬停时提前开始整套动作、抢走紧接着的点击；悬停仍有轻量视觉反馈。
- 首次音频解码慢于 1.2 秒时，最后一次主动点击不会被丢弃。再点另一动物、换场景或静音仍能取消旧声音，背景声音不能抢断主动声音，也不会延迟补播。

## 合并后的布局和互动

猴子在左侧横枝，香蕉与枝条相连；手和食物一起迁移，接触点从统一布局配置读取。树懒在高枝，原有三肢支撑和避开眼睛的取叶路线保留。巨嘴鸟在右上两根独立枝条之间飞行，落点避开松鼠避让区，并与夜间孔雀保留间距。取叶、香蕉再生与熊的三颗枝果统一保存到同一材料账本，换场景不重复生成或遗留手持物。

树林水池加入鱼，身体与气泡仍按真实池面遮罩裁剪；点击鱼或水池会游动、转身、吐泡并产生水面回应。鱼保持无替代叫声。每页仍有两只蝴蝶，蜂蝶与喷水继续共享花朵占用规则。

合并后同时出现喷水和睡眠动物，暴露了水花耗尽反馈额度的问题：现在睡眠符号有独立的有界额度，受点击冷却与总存量限制，喷水时点树懒／蜂巢／夜间巨嘴鸟也能回应。
