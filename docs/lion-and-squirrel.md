# 公狮子与松鼠点击更新 · 2026-10-05

美洲貘从模型库、树冠居民、底部邀请图案和行为分支移除。替换动物为公狮子，安排在平原访客阵容。平原继续是绘本中的轮流来访场景，不展示捕猎。森林不放入来自其他大洲的替换动物。

公狮子保留金黄色身体、浓密鬃毛、四只独立脚掌和尾端毛簇。点击后先抬头，约 0.6 秒后张嘴播放一次真实吼声，轻摆尾巴，再恢复。头部和鬃毛共用颈部关节，下巴绕下颌关节张开，尾根位置不变；站立吼叫时四爪不移动。连续点击不会排队叠加声音。切换场景停止声音并取消未完成动作。夜间也可以互动。

真实录音：[作者公开的公狮子吼叫](https://commons.wikimedia.org/wiki/File:Lion_raring-sound1TamilNadu178.ogg)。作者 Info-farmer，2010-09-04，作者明确标注圈养公狮子并将录音释放到公共领域。原始 Ogg 保存在 `assets/audio/lion-male-commons.ogg`，SHA-256 写入 `assets/credits.json`；处理后的单声道 WAV 保存于 `assets/audio/clean/lion.wav`，内嵌进离线游戏和家长试听页。截取原录音 0.28 秒起的 1.98 秒，保留音高、速度；温和降低固定背景噪声、35 Hz 以下低频杂音，匹配有效叫声响度 −18 dBFS，峰值实测 −12.47 dBFS，边缘渐入渐出。未宣称录音完全无背景声或已完成主观听感审核。

形态与栖息环境参考 [Smithsonian 狮子资料](https://www.nationalzoo.si.edu/animals/lion)：雄性鬃毛、强壮前肢、草原／平原环境。模型是柔和的绘本插画。

松鼠原故障是悬停就自动吃掉唯一的坚果，随后点击被已有动作挡住；吃完后的微小摇头摆尾也缺少可见反馈。现在悬停不消费坚果，首次点击才取食。坚果吃完后再次点击进入可重复的挠脸与明显摆尾动作，手爪保持在眼睛下方，动作结束连续归位。取食中点击有立即的尾巴反馈，不重启取食。原坚果身份和跨页消耗状态保留。

验证：完整 93 项非渲染回归通过；其中 4 项新增松鼠回归、3 项新增公狮子回归。发布审计核对 11 个脚本语法、12 个源模块、17 段嵌入录音及原件哈希、无运行时外部资源。Sharp 静态图检查狮子准备、吼叫、收尾和松鼠挠脸、收尾。状态模拟和静态姿态不等同于浏览器连续动画及声音试听，Chrome 实测未完成。
