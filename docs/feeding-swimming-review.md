# 取食姿态与游鱼交互 · 2026-10-26

这次保留原来的单 HTML 和画风，针对四项实际体验调整。

- 猴子：肩部、肘部和手掌使用一致骨架；肘部不再深折进腹部。香蕉复用枝上形状，直接装在握持组里，与手指一起移动、转腕，实际香蕉尖端接近嘴后才结算取食。手臂用较浅的毛色，使弯肘轮廓可见。原有吃完补香蕉、夜晚休息规则保留。
- 熊：前爪握持、叶片、嘴都用真实变换坐标。摘下的叶子保持枝上的大小和朝向，随握持组转向嘴边；叶尖接触嘴才吃掉。近侧前臂绘制在前景，爪子保持在下颌外侧。站起和落回时逐步调整关节，后爪继续支撑，吃落果后走回站位的逻辑保留。
- 鱼：点击鱼或水池后明显游到另一位置并停留，约 1.8 秒完成；在水池可用范围内选择目标，尾鳍推进、身体轻微俯仰、转向时整个身体一起转。连续点击从当前位置继续，160 毫秒内的重复触碰合并，不传送回起点。两个场景都生效，原水面遮罩保留。
- 树懒：白天、夜晚都能取叶；空闲约 24 秒后第一次短睡约 6.5 秒，之后约 42 秒一轮。当前正在吃叶或收手时推迟打盹；睡觉被点时给 Zzz，随后自行醒来。短暂切换场景保留同一次打盹，叶片再生规则保留。

专项测试见 `tests/feeding-and-swimming.test.cjs`。首批 5 项在修改前均复现失败；另补充了打盹期限遇到取食的检查。原来断言“树懒白天必须睡觉”的测试按新要求更新，通用睡眠反馈改由昼间猫头鹰和树懒短睡共同覆盖。
