# 23 类动物重复互动审查

本轮针对“长颈鹿取叶交互消失”，进一步检查食物耗尽、自动动作提前消费、动作结束后的点击、空闲动作阻挡、来访与离场、昼夜休息及共享花朵占用。已更新离线游戏文件。

## 修复结果

- 长颈鹿：自然入场与悬停不再自动吃掉唯一叶片。点击动物、图案或枝叶取食，嘴接触才摘叶；树枝保留，吃完约 2.2 秒后新叶用 0.45 秒逐渐长大。枝叶可以邀请尚未出现的长颈鹿。
- 树懒：原先唯一叶片永久消耗，夜间背景动作还会提前吃掉它。现在背景动作只张望，点击才取叶；吃完约 4 秒后长出新叶，支持连续取食。白天仍休息，点击出现睡眠符号。
- 通用点击：忙碌时的点击仍给即时反馈，但不会消耗下一次有效动作的冷却，也不排队叠加动作。点击延长访客停留。
- 长颈鹿、猴子、树懒、熊：新食物出现后，点击可结束张望、梳理或嗅闻，马上重新取食。尚无食物时仍有短暂可见动作，不伸手抓空。
- 大象：可达花朵被蝴蝶／蜜蜂占用时，改喷回溪水；水流仍从鼻尖发出，实际命中水面，保留涟漪、水花和彩虹。

叶片与香蕉复用各自唯一的材料身份，生长时间跨场景保存。取食中切走时，尚未吃完的持有物归还枝头，清除手／嘴边物品；已吃完的继续等待生长，避免重复叶片和隐形食物。

## 逐类重复行为

每类完成三次明确请求，先等待上一轮动作落稳。此表记录状态及已有专项回归，不等同于浏览器连续动画观感。

苹果、落地枝果和松鼠坚果保持原有数量归属；苹果可倒出与拾回，坚果吃完后改挠脸回应，不凭空重复生成这些物品。

## 核验

`node --test tests/*.test.cjs`：104 通过，0 失败。新增五项长颈鹿专项回归与六项重复互动恢复回归；新增回归在修复前能复现故障。大象备用喷流检查了实际溪水落点的涟漪，避免只凭进入喷水状态判断成功。

`node tools/audit-repeat-interactions.cjs`：23 类各三次请求，状态记录保存于 `verification/repeat-interaction-audit.json`。睡眠反馈另由 `tests/sleep-feedback.test.cjs` 和昼夜专项测试检查。

`node tools/render-habitat-qa.cjs`：21 张静态姿态图，新增长颈鹿枝叶前／接触／长回、树懒吃完／长回、大象溪水落水。图像位于 `docs/qa/habitat-refinements/`。

发布审计检查脚本编译、当前源模块内嵌、17 项录音字节及原件哈希、离线依赖。本轮未更换声音。

核验边界：本轮使用不渲染的 SVG 状态模拟与 Sharp 静态图。浏览器工具此前拒绝本地文件访问，未绕过该限制；Chrome 连续动画、实际听感和触摸试玩尚未实测。
