# 长颈鹿重复取叶修复 · 2026-10-05

故障根因：首次入场后的自动动作吃掉唯一的叶片，材料状态永久停在 `consumed`。之后点击进入幅度很小的张望动作，没有新的叶子可吃，表现为取叶交互消失。旧实现还会把树枝整组隐藏。

现在自然入场和悬停保留枝叶，点击长颈鹿本体、底部图案或枝叶才发起取食。通过图案主动邀请长颈鹿时，仍会先走到位置再开始取叶；入场期间的点击意图保留到脚掌站稳，不会与行走叠加。

嘴接触叶柄才摘下叶片，树上减少一片，同一叶片移到嘴边并被吃掉。树枝始终可见。吃完约 2.2 秒后，叶片在原位置用 0.45 秒逐渐长大，随后可再次取食。新叶仍使用单一材料身份，避免同时长出多个叶子或重复消费。吃完的新叶出现时，点击可以中断短暂张望，不被冷却吞掉。

切到其他场景时：已经吃完的叶片保留生长截止时间，回来继续长叶；尚在嘴边的叶片归还树枝，手持叶子清除。点击枝叶时，若长颈鹿尚未出现，会邀请它到场再取食。

验证：五项专项非渲染回归覆盖自然入場及悬停、嘴与叶柄实际接触、连续三轮完整取食、枝叶邀请、跨场景消耗／持叶恢复、短暂张望期间重新点击。静态姿态检查图位于 `docs/qa/habitat-refinements/giraffe-leaf-{ready,contact,regrown}.png`。状态模拟和静态图不能替代浏览器连续动画实测。
