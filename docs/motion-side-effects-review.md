# 动作副作用复查 · 2026-10-19

本轮发现了实际边界问题并继续修正，保留已有双场景、23 类动物及真实录音。

| 问题 | 修正与验证 |
| --- | --- |
| 孔雀飞经角鸮第二枝，头部相交 | 用头、躯干、翅膀范围规划路线，预留树上动物和飞行路线的间距；脚收起、身体前倾，地面阴影隐藏；检查逐帧头部间距与静态姿态 |
| 换动物途中召回孔雀，停在半空 | 保存离开前的飞行进度，从原位置继续，不把空中位置当作地面走路位置；落枝后再响应点击 |
| 避障后孔雀白天困在枝头 | 夜枝调整至独立位置；路线规划只缩减端点附近的额外缓冲，不删除原始障碍；圆角采样仍必须避开原始范围 |
| 落枝瞬间多迈一步 | 本帧起始仍在飞行时不累计步行里程、不触发步态，双脚准确恢复枝条接触点 |
| 换访客时蜜蜂瞬间回巢，旁蜂入夜跳回 | 从当前位置规划返巢，预留来访动物入场范围；旁蜂完成已有曲线，落巢后才睡眠；无安全路线时先返巢再让访客入场 |
| 熊吃完落果，原地站起取远处叶片拉长手臂 | 先用已有步态走回取叶站位，再站立取叶；逐帧检查位移和两段手臂长度 |
| 猴子／树懒正在取食时切换昼夜，闭眼继续伸手 | 完成当前取食和物品结算后才进入睡眠姿态；睡眠点击反馈保留 |
| 巨嘴鸟夜间尾巴旋转被 CSS 强制取消 | 移除抵消脚本旋转的强制 transform；保留原旋转中心 |

验证命令：`node --test tests/*.test.cjs`，127 项通过、0 失败。新增 10 项检查，其中 6 项最初可复现失败，另有落枝与避障回归。尾巴的静态渲染检查原先也能通过，不能将它描述为浏览器 CSS 回归的直接证据。

`node tools/audit-repeat-interactions.cjs` 记录 23 类动物各三次重复互动；结果是非渲染状态记录，不代表实际点击观感或声音试听。已有测试同时覆盖身体／头部连接、脚掌接地、条纹随肢体、取食接触、蜂蝶花朵占用、喷水及动作后再次点击。

`node tools/render-motion-side-effects-qa.cjs` 生成 8 个最终静态检查点，位于 `docs/qa/habitat-refinements/motion-final-*`，用于检查上下树、站枝、落地、熊返回后取叶、晨昏取食及蜜蜂回巢。

核验边界：本轮没有在 Chrome 连续播放验证。浏览器策略限制本地文件访问，未以其他浏览器或本地服务绕过。非渲染逐帧检查和静态 SVG 检查不能证明所有时序组合都不会遮挡，也不能替代真机动画、触摸或实际听感验收。
